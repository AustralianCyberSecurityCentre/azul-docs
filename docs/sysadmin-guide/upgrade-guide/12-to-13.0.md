
**Please read this entire document before commencing an upgrade.**

It is **required**  to migrate Azul OpenSearch data to new prefixes as part of this release.
This is required due to changes in the indexing of Azul content that enable faster and more efficient indexing and querying.

It is also **NOT** necessary to migrate Kafka data.

---


## azul-app

### infra

- **important** Minio is now disabled by default if you were using it ensure it's enabled.

- If you are using the infra chart for minio it's recommended you migrate off of it this release. (Minio will be removed in 14.0.0)
    - Seaweed has been provided as a new alternative.


### main

- **important** `security.backend_opensearch_read_role` and `securitybackend_opensearch_write_role` options added and the read role now defaults to `azul-access`, depending on your existing deployment you may have to change it to `azul_read` which was what it was previously or modify your opensearch and OIDC roles to support the new configuration. This has been done to support `azul-access` as the new default into the future.

- `PLUGIN_CAPE_AUTH_TOKEN` renamed to `PLUGIN_SECRET_CAPE_AUTH_TOKEN`

- `plugins.generic.email-olemail` plugin renamed to `email-mail-extract-msg` any configuration should be migrated.

- `plugins.virustotal.pullFromApi` changed from boolean to enum with values ["vt", "azure", "disabled"]

- plugin Virustotal allows pulling from azure now with settings:

```yaml
plugins:
  virustotal:
    config:
      BLOB_CONTAINER: "" # Name of blob container to pull virustotal data from.
      BLOB_FULL_PATH_FORMAT: "" # Filepath when used when pulling virustotal data.
      BLOB_FILE_NAME_FORMAT: "" # format of the virustotal blob data.
      BLOB_HOUR_GRACE_PERIOD: "" # how long to delay downloading a blob for in hours. (to stay behind live)
      BLOB_STABILITY_PERIOD: ""
      BLOB_MAX_RETRY_ATTEMPTS: ""
```

- configurable security context added to base of chart with values:

```yaml
securityContext:
  runAsUser: 21000
  runAsGroup: 21000
  fsGroup: 21000
```

- redis also has a configuration option for setting it's securityContext

```
redis:
  securityContext:
    runAsUser: null
    fsGroup: null
```
