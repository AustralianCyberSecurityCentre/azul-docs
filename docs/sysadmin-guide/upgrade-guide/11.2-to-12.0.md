
**Please read this entire document before commencing an upgrade.**

It is **strongly** recommended to migrate Azul OpenSearch data to new prefixes as part of this release.
If you do not, you will likely experience issues with submission tracking.

It is also **NOT** necessary to migrate Kafka data.

---

Minor changes have been made to values.yaml:

It is highly recommended to set the `priority` field on source reference fields which are important before
reindexing. This is used to enable setting a compound 'key' for source references which doesn't include
the whole reference set (which may contain dates or users which you don't want to pivot on).

`METASTORE_DISABLE_ENTROPY_SIMILARITY` has been removed. Remove references to this field before updating.

New AES encryption functionality has been included for backups. This can be enabled, but a new
label must be used for storing these backups.

An issue with Git synchronisation for Yara plugins has been resolved. If you are looking to utilise
subpaths, look at example uses of `watchPath`. known_hosts checking has been implemented if you currently
utilise other workarounds.
